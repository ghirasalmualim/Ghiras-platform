## التصميم الكامل المحفوظ (كما اعتُمد اتجاهه ثم أُجِّل)

### ٠ · نتيجة تدقيق نموذج الأدوار
`profiles.role` يحمل `'admin'` و`'user'` فقط — لا تمييز معلمة/طالب.
أقل توسعة: قيمة ثالثة `role = 'student'` (لا boolean جديدًا) — كل
فحوص الكود الحالية `=== 'admin'` أو `!== 'admin'` فلا تتأثر.
القاعدة: `student` بلا موافقة موثقة سارية → التسميع مقفل؛ القراءة
والاستماع متاحان دائمًا.

### ١ · Data model — جدول `guardian_consent`
صف لكل رابط مولَّد:
`id · student_id → profiles · token_hash` (hash لا رمزًا خامًا) ·
`created_by · created_at · expires_at` ·
`status: pending → accepted | expired | superseded | revoked` ·
`guardian_name · relationship` (**Consent Evidence لا تحقق هوية**) ·
`accepted_at · privacy_version · terms_version · consent_scope` ·
`revoked_at · revoked_by`.
`CONSENT_LINK_TTL_DAYS = 7` — USER_VALIDATION_REQUIRED.
RLS: لا وصول من المتصفح؛ كل الكتابة عبر مسارات خادم service_role،
وصفحة الموافقة تمرّ بمسار خادم يقارن hash الرمز.

### ٢ · حالات الموافقة (تُشتق ولا تُخزَّن مكررة)
`NO_CONSENT → PENDING_LINK → CONSENTED → REVOKED`.

### ٣ · دورة حياة الرابط
رمز عشوائي ٣٢+ بايت، صلاحية ٧ أيام، استخدام واحد؛ توليد جديد يجعل
أي `pending` سابق `superseded` فورًا؛ القبول يوثّق ويُميت الرمز؛
الانتهاء يُشتق من `expires_at` بلا cron؛ الرابط الميت يعرض صفحة
«انتهت الصلاحية — تواصلوا مع الإدارة» بلا أي معلومة عن الطفل.

### ٤ · ما يراه ولي الأمر (صفحة عامة بلا دخول)
الاسم الأول للطفل فقط + الإفصاح الرباعي + رابطا السياسة والشروط
بإصداريهما + حقلا الاسم والصلة + إقرار الولاية + زر «أوافق».
[LEGAL REVIEW REQUIRED: كفاية Consent Evidence بلا تحقق هوية رسمي]

### ٥ · بوابة التسميع
الفرض في الخادم (مسار recite) لا الواجهة؛ FAIL CLOSED عند تعذّر
قراءة الحالة؛ رسالة عربية لطيفة؛ `user` والأدمِن خارج البوابة؛
القراءة والاستماع لا يمرّان بها.

### ٦ · سحب الموافقة
إداري: زر «سحب» → `revoked` → التسميع يُقفل لحظيًّا؛ الصف يبقى
أثرًا موثقًا؛ يمكن توليد رابط جديد بعد السحب.

### ٧ · Security / abuse safeguards
hash فقط في القاعدة؛ لا رمز في أي log؛ لا معرّف طالب ظاهرًا في
الرابط؛ حد استدعاء على صفحة الموافقة (نمط checkPolicySafe)؛
one-time + إبطال المتزامن؛ لا تعداد (الفاسد لا يكشف السبب)؛
التوليد والسحب أدمِن فقط.

### ٨ · واجهة الأدمِن
شارة حالة لكل حساب student + زرا «إنشاء رابط موافقة» (ينسخ)
و«سحب الموافقة». لا أكثر.

### ٩ · خارج النطاق حتى بعد البناء
لا حساب/لوحة لولي الأمر، لا إرسال آلي، لا تحقق هوية رسمي، لا
موافقة لكل تسميع، لا تسجيل ذاتي لولي الأمر (TARGET DESIGN في
سياسة الخصوصية، مرحلة 15+)، لا تعدد أولياء.

### ترتيب البناء عند إحيائه
migration (تُكتب وتُراجع، Staging أولًا ثم الإنتاج بيد صاحبة
المنصة) → مسارات الخادم → صفحة الموافقة → شارات اللوحة → بوابة
recite → اختبارات نصية.
